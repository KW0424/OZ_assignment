git push : 로컬 > 원격 업로드
git pull : 원격 > 로컬 다운로드 (fetch + merge)
(변경된 커밋을 가져옴)

get clone : 원격 > 로컬 다운로드 (전체 코드를 동기화)
git fork : 다른 원격 > 내 원격 복제
